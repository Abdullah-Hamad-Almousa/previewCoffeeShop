# Mystic Coffee Product Replacement Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Replace old products with 10 new Mystic-themed products. Each product shows its Mystic name (big) + real-world name (small subtitle). Delete non-matching old products.

**Approach:** Add `real_name_en`/`real_name_ar` columns to products table. Rename 4 matching products (keep their UUIDs so reviews/orders stay). Delete 4 non-matching products (cascade deletes their reviews/orders). Insert 6 new products. Re-seed reviews for all 10.

## Task 3: Add helper for real name

**Objective:** Add `getProductRealName` to helpers, same pattern as `getProductName`.

**Files:**
- Modify: `lib/helpers.ts`

```typescript
/** Get localized real-world product name */
export function getProductRealName(
  product: Pick<Product, 'real_name_en' | 'real_name_ar'>,
  isAr: boolean
) {
  const name = isAr ? product.real_name_ar : product.real_name_en;
  return name ?? null;
}
```
